# Plant-Disease-Classification
Dự án nhận diện và phân loại 38 loại bệnh trên lá cây sử dụng mô hình học sâu **ResNet18** kết hợp giao diện web **Streamlit**.
## 📌Giới thiệu đề tài
- Đề tài số 23: Nhận dạng bệnh lá cây dựa trên tập dữ liệu PlantVillage.
- Công nghệ sử dụng: Python, Pytorch, Streamlit, ResNet18.
## 📂Cấu trúc thư mục dự án
- `app.py`: Mã nguồn giao diện ứng dụng Streamlit chạy offline.
- `plant_disease_resnet18.pth`: File trọng số mô hình đã huấn luyện.
- `notebooks/`: Chứa các file Jupyter Notebook phục vụ cho việc khám phá dữ liệu (EDA).
